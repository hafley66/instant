## Data shape and views

```text
Source session A
  turns 42, 43
       |
       | quoted by
       v
  Comment 17
    quote: selected passage
    note: please explain this
    targets: [{session:A, turn:42}, {session:A, turn:43}]
       |
       | agent_turn_comment_fork
       v
  Fork link: comment_id, lane, branch, brief, created_ts
       |
       v
  Child lane B (parent A)
    bound session B1
      initial brief
      independent conversation
    live pane -> Instant TUI
```

Parentage supplies family nesting. The comment link supplies passage provenance. Proposed Instant projection, not current shipped fields:

```ts
{
  id: 'B', kind: 'lane', parentId: 'A', sessionId: 'B1',
  relation: 'fork',
  origin: {
    commentId: 17,
    targets: [{ session: 'A', turn: 42 }, { session: 'A', turn: 43 }],
  },
  state: 'live', children: [],
}
```

Presentation examples: family tree shows `fork` beside execution state; source passage shows a linked child and its state; child TUI provides `From A, turns 42-43` navigation. Child lanes may recursively have forks.

Creation sequence: capture -> persist/flush comment -> resolve numeric comment ID -> spawn with explicit source parent -> record fork link -> bind session/attach TUI. Preserve provenance independently of pane lifetime. Failure/retry semantics remain to be specified.
