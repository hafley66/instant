# Session: instant-preview-canvas-research

## Goal
Keep Instant's SVG/D2/Markdown preview paths reliable and research a file-backed, agent-controlled spatial canvas that can compose terminals, sessions, files, diagrams, and interactive artifacts.

## Problem/Context
- Large D2-generated SVGs showed labels and light panels while path-based nodes, arrows, and MathJax glyph geometry disappeared.
- DOMPurify retained 217 path elements but preserved only 10 `d` attributes because the custom URI policy treated path data beginning with letters as a rejected URI-like value.
- Markdown links highlighted but did not open because the viewer consumed clicks and passed HTTP URLs to Tauri `openPath`, which accepts filesystem paths. Non-Markdown local targets were also consumed without routing.
- The requested future workspace resembles a FigJam/Miro paged canvas where agents can place or update artifacts at the cursor or by stable filesystem/session identity.

## Solution/Approach
- Added `ADD_URI_SAFE_ATTR: ["d"]` to both DOMPurify passes in `src/0_svgSanitize.ts`.
- Added a repository-owned SVG Playwright fixture containing path-based linked geometry and a connector.
- Added `MdviewHost.openHref(href, sourcePath)` and wired it to `openDocumentHrefInInstant` at the composition root.
- Added Playwright coverage that clicks a rendered Markdown link and snapshots the exact href plus source document passed to the host.
- Researched direct product references and reusable boundaries: Cate, TermCanvas, PenEcho, Dim0, tldraw agent kit, React Flow, Excalidraw MCP, JSON Canvas, MCP Apps, Cytoscape, ELK, Phoenix, and Langfuse.
- Research identifies TermCanvas and Cate as the closest coding-session products; PenEcho as the closest cursor/selection-to-agent placement interaction; Dim0 as the closest board-aware generated-artifact workspace.

## Key Insights
- Exact SVG failure count: source had 217 path `d` attributes; sanitized output had 10 before the fix and 217 after it.
- Camera movement and artifact movement must reuse cached SVG output rather than rerender D2/Mermaid.
- Stable artifact identity should come from filesystem paths, harness/session IDs, or explicit inline identity, never terminal text inference.
- JSON Canvas supplies a readable local file interchange layer with positioned text/file/link/group nodes and edges.
- MCP Apps supplies a portable sandboxed interactive-artifact boundary but leaves spatial placement and durable identity to the host.
- Existing Instant seams already cover four harness stores, an `instant-harness` JSON CLI, tmux persistence, file routing, file watches, diagram rendering, and session relationships.
