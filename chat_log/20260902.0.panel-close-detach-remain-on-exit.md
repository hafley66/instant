# Session: panel-close-detach-remain-on-exit

## Goal
Stop tmux panels from killing their tmux session on close, both in the instant app and system tmux.

## Current State
DONE. All code changes applied and verified. System tmux fixed live. instant needs an app restart to pick up the Rust change.

## Problem/Context
User rage: closing panels in instant killed the tmux session under them. Diagnosis found three mechanisms:
1. `closedTabFate` (src/0_closedTabFate.ts) returned "kill" for any agent-looking tab on panel close, then `kill_session` (src-tauri/src/pty.rs:904, `tmux kill-session`) fired.
2. Explicit kills (sidebar × at src/worktrees.ts:259, agent-menu Kill at src/worktrees.ts:927) — intentional, kept.
3. Self-exit: no `remain-on-exit` anywhere, so a process exiting took pane -> window -> session. System tmux also had `remain-on-exit off`, `exit-empty on`, no ~/.tmux.conf.

User decisions via AskUserQuestion: panel close ALWAYS detaches (explicit kills stay the only kill paths); instant sets remain-on-exit on sessions it creates. Lanes/boop-owned sessions untouched (boop beep lane prune owns them).

## Solution/Approach
- src/terminal.ts: `exitOrDetachTab` and `closedTabFate` call sites deleted; `onTermClosed` closeChain now just `invoke("close_pty", { id })` (detach; tmux session survives). Fate-input captures (tabMeta/proc/sessionListed/isViewer/isGraphics) removed from `onTermClosed`.
- Deleted src/0_closedTabFate.ts + its test.
- src/tabs.ts + src/worktrees.ts: stale comments referencing exitOrDetachTab/kill behavior reworded to 2-line max (repo comment-prod hook: max 2 consecutive comment lines).
- src-tauri/src/pty.rs `enable_mouse(name, respawn)` (was `enable_mouse(name)`): per-session retry loop now sets `mouse on` AND `remain-on-exit on`; after the loop, if `#{pane_dead}` is 1, `respawn-pane -k -t <name> [command]`. Caller at pty.rs:599 (reload path) passes None; caller at pty.rs:739 passes the tab command only when the spawn creates its own session (attach_only or tmux_target -> None, lanes protected).
- ~/.tmux.conf created: `set -g remain-on-exit on`, `set -g exit-empty off`, `set -g detach-on-destroy off`; applied to running server via `tmux set-option -g`.
