## Rules
- The user's words: no more useless playwright tests written by AI, no mocks except harness replay, and ~1 golden per behaviour instead of granular asserts.
- Test style: whole-output `toMatchInlineSnapshot`/`toMatchSnapshot`; no `toBeDefined`; no hand-built DOM via `document.createElement` standing in for real components; no shared setup copied across tests.
- **Time cap**: no command longer than 300s. Do not run playwright e2e suites. Test counts come from `vitest list`, `playwright test --list`, and `cargo test -- --list`.
- RxJS law: libraries never `.subscribe()`.
- Commit only the plan files on the branch. Do not push.
